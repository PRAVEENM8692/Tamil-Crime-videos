# Kutty Kadhaigal – Tamil kids story Shorts (auto)
3 Shorts/day (9:00, 14:00, 19:00 IST). Multi-voice Tamil cartoon stories, auto-uploaded to YouTube.
Secrets: LLM_API_KEY, YT_CLIENT_ID, YT_CLIENT_SECRET, YT_REFRESH_TOKEN (optional LLM_BASE_URL, LLM_MODEL).
Variables (optional): CHANNEL_NAME, MADE_FOR_KIDS, YT_PRIVACY (private/unlisted/public), BGM_FILE.
Put your own BGM mp3 in assets/ and your logo as assets/logo.png (otherwise an animated letter badge is used). No subtitles; speaker name tags only.
PUPPETS=true by default (characters are cut out and animated); set variable PUPPETS=false to use plain scene pictures.
