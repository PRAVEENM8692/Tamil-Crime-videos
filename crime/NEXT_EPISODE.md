# Making the next episode (how episode 1 "alavandar" was made)

Case folder: crime/<case>/ with script.txt, scenes.json, plan.json, youtube.json.
1. script.txt: sections `## 01 hook` ... `## 10 ending` (see crime/alavandar/script.txt). Spoken colloquial Tamil, 6-8 min, ~800-900 words. Hook -> disclaimer -> background -> investigation -> clues -> "what would you do?" question -> answer -> arrest -> court verdict -> ending with the question for comments and a teaser of the next case. Only court-decided cases; facts checked on the web; no real names of living private persons beyond what the court record says.
2. scenes.json: {"shots":[{"n":1,"scene":"..."} ... ~60-65 (medium: one new picture about every 7 seconds; the daily neuron limit allows ~95 klein pictures)]}: comic pictures drawn by Cloudflare FLUX.2 klein 4B (16:9, 1280x720, ~105 neurons a picture; daily free limit 10,000 neurons per account, resets 5:30 AM IST; MODEL=schnell gives old squares). Wording rules: no "blood", no years/numbers (they turn into printed text), write "clean floor"; object-only still lifes for sensitive moments; never real photos.
3. plan.json: {"bgm_volume":0.07,"pictures":[{"sec":"01","cue":null,"n":1},...],"tags":[{"sec","cue","text","style":"tag|big|card","delay","for"}],"episode":{"num":N,"title":"THE ... CASE","sub":"CITY | YEAR"}}. Cue = a phrase of the section text where the picture/tag starts.
4. Workflows (Actions, input case=<case>): Crime Story Full Voice -> Crime Story Pictures -> Crime Story Build Video (puts the video on branch video-<case>) -> Crime Video Upload (private). Voice is Gemini Charon, plain; crime/tts_clean.py removes Gemini's end-of-clip noise burst.
5. youtube.json: title "EP N | <hook> | Solved Crime Files - Tamil", description with chapters (times: hook, intro at the end of the hook, then each section start + 13 s for the intro), tags, pinned_comment. Thumbnail: 1280x720 jpg from crime/thumb.py, which has 4 looks (A dark left panel, B full picture + bottom band, C red frame, D yellow right panel); the layout rotates with the episode number so no two neighbouring thumbnails look alike (or pass a 7th argument A-D). Built like assets/crime_<case>_thumb.jpg (comic picture on the right, Tamil headline left, EPISODE N tag, channel name). Pass THUMB path via the upload workflow env if different.
The video is uploaded PRIVATE; the owner makes it Public himself and pins the comment. Do not set the AI-generated/altered-content flag.
